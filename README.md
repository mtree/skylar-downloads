# Skylar na Windows

**[Pobierz najnowszą wersję gry (Windows x64, ZIP)](https://github.com/mtree/skylar-downloads/releases/latest/download/Skylar-Win64.zip)**

Wypakuj całe archiwum do folderu, np. `D:\Gry\Skylar`, i otwórz `Skylar.exe`.
W grze znajdziesz garaż i tor Laguna Seca. Przy pierwszym uruchomieniu kreator pomoże przypisać kierownicę i pedały DirectInput.
Jeżeli Windows zgłosi brak bibliotek Visual C++, uruchom dołączony `Engine\Extras\Redist\en-us\vc_redist.x64.exe`.

Ten sam link prowadzi do najnowszej sprawdzonej paczki po każdym wydaniu. [Wszystkie wydania](https://github.com/mtree/skylar-downloads/releases)
